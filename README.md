# Лабораторная работа № 1 — Todo List

## Описание проекта

Приложение Windows Forms на языке C# для управления списком задач. Позволяет создавать задачи, изменять их названия, устанавливать приоритет и срок выполнения, отмечать выполнение и удалять задачи.

## Реализованные возможности

- Добавление, переименование и удаление задач.
- Отметка задач как выполненных.
- Установка приоритета: низкий, обычный или высокий.
- Установка необязательного срока выполнения для каждой задачи.
- Выделение красным цветом названия и срока просроченной невыполненной задачи.
- Сохранение и загрузка задач в формате JSON.
- Поиск задач по названию.
- Фильтрация: все, активные и выполненные.
- Сортировка по приоритету.
- Отображение количества задач и карточек с цветами по приоритету.

## Технологии

- C#
- .NET 8
- Windows Forms
- JSON для хранения данных.

## Структура проекта

- `Program.cs` — точка входа приложения.
- `TodoItem.cs` — модель задачи, включая название, приоритет, статус и срок выполнения.
- `TodoList.cs` — управление списком задач, фильтрация, сортировка и сохранение данных.
- `MainForm.cs` — интерфейс и обработка действий пользователя.
- `lab1-todo.csproj` — настройки проекта.

## Запуск

1. Открыть `lab1-todo.csproj` в Visual Studio.
2. Убедиться, что установлен .NET 8 SDK.
3. Дождаться загрузки зависимостей.
4. Запустить приложение клавишей `F5`.

## Проверка работы

Проверьте добавление задачи с датой и без даты, сохранение и загрузку срока после перезапуска. Для проверки просрочки укажите прошедшую дату: у невыполненной задачи название и срок должны отображаться красным цветом. У выполненной задачи красное выделение просрочки не применяется. Также проверьте добавление, переименование, удаление, отметку выполнения, поиск, фильтрацию, сортировку и сохранение задач.
